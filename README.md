# sjolystinnovation-app

Website for Sjølyst Innovation AS.

## Stack

Next.js 16 App Router, TypeScript, Tailwind CSS 4, Vitest.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

The site runs on empty environment variables. Only the contact form needs them filled in.

## Scripts

| Command | Does |
| --- | --- |
| `npm run dev` | Development server on port 3000 |
| `npm run build` | Production build |
| `npm start` | Serves the production build |
| `npm test` | Vitest |
| `npm run lint` | ESLint |
| `npm run prepare-images` | Rebuilds the product photos in `public/products` |

## Environment

| Variable | Used for |
| --- | --- |
| `BREVO_API_KEY` | Brevo v3 API key |
| `BREVO_SENDER_EMAIL` | Sender address, must be verified in Brevo |
| `BREVO_SENDER_NAME` | Sender name |
| `CONTACT_TO_EMAIL` | Recipient of contact form enquiries |
| `SITE_ENV` | `prod` allows crawling, anything else serves `Disallow: /` |

The four Brevo variables are read inside the request handler. `SITE_ENV` is a Docker build argument.

## Content

| What | Where |
| --- | --- |
| Projects | `src/lib/projects.ts` |
| Products | `src/lib/products.ts` |
| Company details | `src/lib/company.ts` |
| Product photos | `public/products`, generated by `scripts/prepare-images.mjs` |
| Project logos | `public/projects`, or fetched from the project's own `/api/branding` |

## Deployment

Image [`sondresjo/sjolystinnovation-app`](https://hub.docker.com/r/sondresjo/sjolystinnovation-app)
on Docker Hub, chart `sjolystinnovation-app` in
[tumogroup-charts](https://github.com/sondresjolyst/tumogroup-charts), applied by Flux from
[tumo-flux](https://github.com/sondresjolyst/tumo-flux) to `sjolystinnovation-dev` and
`sjolystinnovation-prod`.

A push to `main` builds the `dev` tag. A release-please release builds `vX.Y.Z`, tags it `latest`
and opens a chart bump against
[tumogroup-charts](https://github.com/sondresjolyst/tumogroup-charts). Cluster secrets are created
by [`scripts/sjolystinnovation/bootstrap.sh`](https://github.com/sondresjolyst/tumo-platform/blob/main/scripts/sjolystinnovation/bootstrap.sh)
in [tumo-platform](https://github.com/sondresjolyst/tumo-platform).
